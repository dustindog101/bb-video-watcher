# Architectural Decisions & Reasoning: bb-video-watcher

## 1. Decision: Browser Automation vs. Pure HTTP Forgery

### Option A: Pure HTTP API Packet Forgery
- **Approach**: Emulate OIDC tokens and forge POST requests to `/services/player/logPlayTime`.
- **Drawbacks**:
  - Requires signing RS256 JWTs and replicating Blackboard gateway handshakes.
  - Heartbeat payloads require in-memory session UUIDs and bitmask hashes computed by obfuscated client JS bundles.
  - Fatal velocity risk: Sending synthetic intervals without wall-clock delay triggers server-side rejection or academic integrity flags.
- **Verdict**: ❌ Rejected as unsafe and fragile.

### Option B: Playwright Chromium Browser Automation
- **Approach**: Launch Chromium with `--mute-audio`, load active cookies from `.session/cookies.json`, navigate through the LTI entry point, and let the real YuJa player run natively while manipulating `video.playbackRate`.
- **Advantages**:
  - 100% authentic telemetry: Real heartbeat beacons and interval hashes are generated by YuJa's own scripts.
  - Silent: Audio is hardware-muted via Chromium flags and DOM properties.
  - Resource-efficient: Runs headlessly with low CPU overhead.
  - Reliable grade passback: The LMS receives authentic Assignment and Grade Services (AGS) completions.
- **Verdict**: ✅ Selected.

## 2. Decision: Safe Playback Velocity Bounds

- **Default Speed**: **2.0x**
  - Universally supported by HTML5 and YuJa UI.
  - Cuts viewing time by 50% while maintaining an unflagged footprint in instructor analytics.
- **Speed Clamp**: Maximum allowed is **4.0x**.
  - Speeds exceeding 4.0x cause HLS chunk starvation and unrealistic session duration timestamps.
- **Stealth Micro-Jitter**:
  - When `--stealth` is active, the engine introduces subtle $\pm 0.15\text{x}$ rate oscillations every 35–60 seconds, creating an authentic human engagement profile.

---

## 3. Decision: Gradebook Correlation & Verification

- The tool does not simply assume completion when the video element reaches the end.
- It waits for `video.ended == true`, clicks any end-card submission buttons, waits 6 seconds for final telemetry beacons to flush, and queries Blackboard's Gradebook REST Fast-Path (`/learn/api/public/v2/courses/{cid}/gradebook/columns/{col_id}/users/{user_id}`).
- This provides deterministic confirmation of points earned.
